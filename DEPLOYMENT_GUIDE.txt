🚀 STEP 1: DEPLOY BACKEND TO VERCEL (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Vercel is free, fast, and perfect for this. Here's how:

1️⃣  Create Vercel Account
    - Go to: https://vercel.com/signup
    - Sign up with GitHub, GitLab, or email
    - Takes 30 seconds

2️⃣  Create GitHub Repository
    - Go to: https://github.com/new
    - Repository name: "voice-to-cart"
    - Keep it PUBLIC
    - Click "Create repository"

3️⃣  Upload Your Files to GitHub
    - Clone the repo to your computer:
      $ git clone https://github.com/YOUR_USERNAME/voice-to-cart.git
      $ cd voice-to-cart

    - Copy these files into the folder:
      • voice-to-cart-backend.js → api/index.js
      • package.json
      • .env.example → .env.local

    - Create package.json file:
      {
        "name": "voice-to-cart",
        "version": "1.0.0",
        "description": "Voice-to-cart for Shopify",
        "main": "api/index.js",
        "scripts": {
          "start": "node api/index.js",
          "dev": "node api/index.js"
        },
        "dependencies": {
          "express": "^4.18.2",
          "cors": "^2.8.5",
          "axios": "^1.6.2",
          "dotenv": "^16.3.1"
        }
      }

    - Create .env.local:
      SHOPIFY_CLIENT_ID=983a67e105fdce76538ee7c588f6d321
      SHOPIFY_SECRET=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
      SHOPIFY_STORE=genfury.myshopify.com
      AUTOMATION_TOKEN=atkn_8e2263970508af62a3d08423b91e2f934b168f87193b131a4a8856d76588 8ec0
      PORT=3000

    - Push to GitHub:
      $ git add .
      $ git commit -m "Initial voice-to-cart setup"
      $ git push origin main

4️⃣  Deploy to Vercel
    - Go to: https://vercel.com/new
    - Click "Import Git Repository"
    - Select your "voice-to-cart" repo
    - Set Environment Variables:
      ✓ SHOPIFY_CLIENT_ID = 983a67e105fdce76538ee7c588f6d321
      ✓ SHOPIFY_SECRET = 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
      ✓ SHOPIFY_STORE = genfury.myshopify.com
      ✓ AUTOMATION_TOKEN = (paste full token)
      ✓ PORT = 3000

    - Click "Deploy"
    - Wait 1-2 minutes...
    - Get your URL: https://voice-to-cart-XXXXX.vercel.app

5️⃣  Test Your Backend
    - Go to: https://voice-to-cart-XXXXX.vercel.app/api/health
    - Should see: { "status": "ok", "store": "genfury.myshopify.com" }


✅ Backend is LIVE! Save your URL for next step.

4️⃣  Add the Frontend Code
    - Copy ALL content from: voice-to-cart-frontend.html

5️⃣  Save & Test

6️⃣  If It Works → Publish Theme

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Problem: Mic button doesn't appear
   → Check if you pasted the code at the bottom of theme.liquid
   → Try refreshing page (Ctrl+F5 or Cmd+Shift+R)
   → Check browser console for errors

❌ Problem: Voice recognition not working
   → Make sure you're using HTTPS (genfury.com has SSL)
   → Try Chrome/Edge first
   → Check if mic permission is granted
   → Say clearly and wait for "✓" in transcript

❌ Problem: Products not found
   → Check backend URL is correct (replace XXXXX with your Vercel URL)
   → Verify Shopify API credentials are correct
   → Try searching by exact product name first

❌ Problem: "Add to Cart" button doesn't work
   → Check Vercel backend is running
   → Look at browser console for error messages
   → Verify variant IDs are correct

❌ Problem: Vercel deployment fails
   → Check environment variables are set correctly
   → Make sure .env.local file is in root of repo
   → Restart deployment

❌ Still having issues?
   → Open browser DevTools (F12)
   → Go to Console tab
   → Look for error messages
   → Share those error messages with support
