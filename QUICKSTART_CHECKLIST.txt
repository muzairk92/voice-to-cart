TROUBLESHOOTING QUICK REFERENCE
═════════════════════════════════════════════════════════════════════════

Issue: 🎤 button not showing
  → Refresh page with Ctrl+F5 (Cmd+Shift+R on Mac)
  → Check browser console (F12) for errors
  → Verify code was pasted at bottom of theme.liquid

Issue: Mic not recording voice
  → Check browser permissions (allow microphone)
  → Try closing and reopening browser
  → Test in different browser
  → Make sure you have a working microphone

Issue: Products not found for valid search
  → Check Vercel backend is running
  → Test backend URL in browser: https://voice-to-cart-XXXXX.vercel.app/api/health
  → Check Shopify API credentials are correct
  → Try exact product name first

Issue: "Add to Cart" button not working
  → Check Vercel backend logs
  → Verify variant IDs in Shopify
  → Try refreshing the page
  → Check network tab in DevTools (F12)

Issue: Vercel deployment failed
  → Re-check all environment variables
  → Verify .env.local file exists in root
  → Check package.json is correct
  → Try redeploying manually
